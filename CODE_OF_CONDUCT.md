# Code of Conduct

Be respectful and constructive. Welcome beginners, ask clarifying questions and give specific feedback about work rather than people. Harassment, discrimination, threats, spam and publishing another person's private information are not accepted.

Maintainers may edit or remove harmful contributions and restrict participation when needed. To report an incident, contact the maintainers through the repository without posting private details publicly. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
